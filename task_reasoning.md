This task falls under **Kernel-Framework Integration** as its primary category, with **Tensor memory/Layout** as a secondary category. It evaluates an agent's capability to resolve silent layout corruption and missing meta-tensor lowering in a custom C++ PyTorch extension implementing a sparse embedding index-scaling operation (`sparse_gather_scale`). This tests real-world proficiency in writing stride-aware custom ATen operators that interact correctly with `torch.compile` and Inductor's fake tensor propagation engine.
